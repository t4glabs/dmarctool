📡 Other domains

Domains visible in your Mailgun and Postmaster Tools accounts that aren't tracked in the main dashboard -- friends'/clients' sites you manage that don't need daily/weekly DMARC review, but are still worth an occasional glance. A domain only ever shows up in the main Overview once a DMARC report for it has actually been ingested; if it has no DMARC record published at all, it never will, no matter how much time passes -- this page is the only place that gap would ever surface. Computed live on every load (real DNS lookups + two live APIs across every untracked domain) rather than cached, so it can take several seconds -- nothing here is stored or scheduled.
